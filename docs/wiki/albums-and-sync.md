# Albums And Sync

Moxzk รองรับทั้งงาน local และ cloud album สองอย่างนี้ไม่ใช่สิ่งเดียวกัน

## Without Login

ผู้ใช้สามารถทำงาน local ได้โดยไม่ต้อง login:

- เพิ่มรูป
- คลีน/แปล ถ้า local tools พร้อม
- แก้ region
- export
- save เป็นไฟล์ `.moxzk`

เหมาะกับงานส่วนตัว งานทดลอง และการย้ายไฟล์เอง

## With Login

เมื่อ login แล้ว ผู้ใช้สามารถบันทึกเข้า album ได้

- Album เก็บงานและรูปที่บันทึกไว้กับบัญชี
- เปิด album แล้วเข้า editor โดยตรง
- บันทึกกลับเข้า album หลังแก้ไข
- ระบบตรวจสิทธิ์เจ้าของงานก่อนเข้าถึงไฟล์

## Local Project File

ไฟล์ `.moxzk` ใช้เป็น portable project file:

- เก็บงานไว้เปิดกลับภายหลัง
- เหมาะกับทำงานแบบไม่ต้อง login
- เหมาะกับย้ายงานข้ามเครื่องเมื่อแนบ asset ครบตาม format ที่แอปรองรับ

อย่าสับสนกับ autosave draft เพราะ draft มีไว้กู้คืนงานล่าสุด ไม่ใช่ archive ระยะยาว

## Privacy Boundary

งาน local processing เช่น PanelCleaner และ Ollama รันบนเครื่องผู้ใช้ แต่ album cloud path ต้องส่งรูปและข้อมูลงานไปเก็บกับบริการของโปรเจค

หน้า public จึงไม่ควรเขียนว่า “รูปไม่ออกจากเครื่องเลย” แบบ absolute ให้ใช้ข้อความที่ชัดกว่า:

> งานคลีนและแปลรันจากเครื่องคุณเป็นหลัก ส่วนการบันทึก album จะใช้ cloud ตามบัญชีที่คุณเลือก

## Moving Machines

วิธีที่แนะนำ:

1. save เป็นไฟล์ `.moxzk`
2. ย้ายไฟล์ไปเครื่องใหม่
3. ติดตั้ง Moxzk และ dependency ที่จำเป็นบนเครื่องใหม่
4. เปิดไฟล์ `.moxzk`
5. ตรวจรูป, region, font และ export path อีกครั้ง
